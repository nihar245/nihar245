## 🚀 Featured Projects

### 🎙️ Multilingual AI-Generated Speech Detection
Developing an audio classification pipeline to distinguish AI-generated speech from human speech across Indian languages and English.

- **Core technologies:** Python, PyTorch, WavLM, AASIST-inspired classification, OC-Softmax, Hugging Face, FastAPI.
- Combined complementary classification heads for audio authenticity detection.
- Designed preprocessing and sliding-window inference for longer audio recordings.
- Built a REST API for model inference and deployment.

### 🍽️ Restaurant AI Voice Copilot
An AI-powered restaurant assistant combining conversational voice interaction with data-driven decision-making.

- **Core technologies:** Python, machine learning, voice AI, backend APIs.
- Integrated voice-based ordering concepts with demand forecasting using XGBoost.
- Focused on practical restaurant workflows and operational efficiency.

### 🚦 SkyGrid AI — Intelligent Traffic Management
An AI-based traffic management concept focused on real-time routing and coordinated decision-making.

- **Core technologies:** AI/ML, backend development, LLM-based coordination.
- Designed workflows for intelligent traffic response and routing.
- Project target/result reported in earlier project work: reduced response time from approximately 25 minutes to under 15 seconds.

### 📄 Enterprise RAG & Document Intelligence
A retrieval-augmented generation system for document ingestion, indexing, retrieval, and question answering.

- **Core technologies:** FastAPI, PostgreSQL, pgvector, BGE-M3, semantic chunking, Gemini.
- Explored hybrid retrieval and hierarchical document representations.
- Designed a pipeline connecting document processing, embeddings, retrieval, and answer generation.

### 🗄️ Natural Language to SQL
An AI-powered interface that translates natural-language questions into database queries.

- **Core technologies:** Next.js, FastAPI, LLMs, ClickHouse, Apache Druid.
- Worked on schema discovery, SQL planning, and database-backed question answering.
- Focused on making analytical data more accessible through conversational interfaces.
